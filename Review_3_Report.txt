3. Comprehensive Database Schema Dictionary (7 Normalized Tables)

1. **`dataset_versions`**: Stores physical training dataset snapshots with SHA-256 content hashes, record counts, and JSON schema definitions.
2. **`feature_definitions`**: Tracks computed feature names, target entity types (`user`/`item`), and exact mathematical transformation logic.
3. **`model_records`**: Stores model version tags, Git commit SHAs (`git_commit_sha`), hyperparameter configurations, offline metrics (RMSE, NDCG@5), and physical artifact SHA-256 checksums (`artifact_sha256`).
4. **`approval_records`**: Enforces formal multi-party compliance sign-offs (`APPROVED`/`REJECTED`) by compliance officers before model promotion.
5. **`deployment_records`**: Controls active production serving endpoints with temporal deployment tracking.
6. **`inference_audit_logs`**: Persists immutable point-in-time snapshots containing candidate item lists, as-of feature vectors, raw float scores, and final ranked recommendations.
7. **`feature_store_events`**: Append-only event stream log with unique SHA-256 event fingerprints (`event_key`) for boundary deduplication.
